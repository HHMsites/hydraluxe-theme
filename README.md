# HydraLuxe WordPress theme

Draft landing theme v0.1.1. Profile cards are equal full width, Stephanie first and Melissa second; both use matching portrait/content columns and heading sizes. Includes local fonts, logos, four landing patterns and a selectable draft homepage template.

Two headshots are intentionally omitted pending permission to publish them in this public repository: assets/images/stephanie-sines.jpg and assets/images/melissa-schlachter.jpg. Their image blocks still reference those filenames. Do not deploy this incomplete draft until assets are resolved.

Static checks: JSON parsing, block-comment nesting and referenced local files were checked before packaging. WordPress activation, editor validation and frontend/mobile rendering have not been tested. Set Site Logo and site icon in WordPress. No merge, deployment or DNS change is included.
